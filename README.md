# TraceDiag

WinForms-утилита для диагностики маршрута до удалённого хоста: ICMP-трассировка, reverse DNS,
статистика потерь и проверка размера пакета. Все пользовательские строки вынесены в `Strings.cs`,
вся логика разбита на небольшие статические модули.

## Возможности

- Трассировка маршрута с инкрементом TTL от 1 до 30 и остановкой при достижении цели.
- Reverse DNS для каждого обнаруженного узла.
- Проверка узлов пакетами разных размеров:
  - галочка **«Динамический размер пакета»** включена — размеры `64 → 128 → … → максимум`;
  - галочка выключена — только максимальный размер из поля ввода (64–65534 байт).
- Настраиваемое число попыток на узел (1–1000).
- Точная статистика по каждому узлу: средний/мин/макс/последний пинг, отправлено/получено,
  потери в процентах. Среднее считается из всех сохранённых RTT-замеров.
- При 100% потерях узел получает статус `не отвечает`, дальнейшие проверки этого узла
  пропускаются (защита от запрета ICMP и ограничений размера пакета).
- Анализ потерь: сравнение соседних узлов, отделение разовых потерь от повреждённого сегмента.
- Таблица статистики над полноширинным логом, подсветка проблемных строк.
- Выбор размера шрифта лога (справа), крупная кнопка `Run` справа.
- Полноэкранный режим: `F11` — включить/выключить, `Esc` — выйти.
- Системная иконка сети, файловое логирование и сохранение настроек в JSON.

## Требования

- Windows 10/11.
- .NET 10 SDK (для сборки) или .NET 10 Desktop Runtime (для запуска готового EXE).

## Сборка и запуск

```powershell
dotnet build TraceDiag.slnx -c Release
.\TraceDiag\bin\Release\net10.0-windows\TraceDiag.exe
```

## Тесты

```powershell
dotnet test TraceDiag.slnx -c Release
```

67 юнит-тестов (xUnit) покрывают планировщик размеров пакета, статистику узлов,
маппинг ICMP-ответов, конфигурацию и логирование, диагностические модули и полный
цикл `TraceDiagnosticsService` с тестовыми фейками.

## Структура

```text
TraceDiag/
  Models/                    модели данных и расчёт статусов
  Services/                  ICMP, DNS, конфиг, логирование
  Services/Diagnostics/      маршрут, проверка узлов, анализ потерь
  Ui/                        фабрики контролов, layout, поток запуска
  Strings.cs                 все пользовательские и лог-строки
TraceDiag.Tests/
  TestData/                  фейки ICMP/DNS/логера и прогресса
  *Tests.cs                   юнит-тесты
```

## Данные приложения

- Настройки: `%LOCALAPPDATA%\TraceDiag\settings.json`
- Логи: `%LOCALAPPDATA%\TraceDiag\logs\tracediag-yyyyMMdd.log`

Скомпилированные файлы (`bin/`, `obj/`) в репозиторий не попадают.
