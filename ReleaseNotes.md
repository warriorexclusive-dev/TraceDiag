# Release Notes

История изменений TraceDiag. Готовые сборки публикуются на страницах
[Releases](https://github.com/warriorexclusive-dev/TraceDiag/releases).

## 1.1.2

- Количество попыток по умолчанию увеличено с `4` до `100`.
- Диапазон настройки остался прежним: `1–1000`.
- Значение по умолчанию подходит для передачи лога провайдеру и замера процента потерь.
- Добавлен тест на значение по умолчанию.
- 75 юнит-тестов проходят успешно.

## 1.1.1

- Поиск хостов вынесен в отдельную модель `HostDiscovery`.
- Поиск выполняется последовательно по TTL: до `3` проходов с интервалом `1` с,
  пакет `64` байт, флаг `DontFragment` и таймаут `5` с.
- TTL без ответа добавляются в таблицу со статусом `не отвечает` и помечаются как
  пропускаемые; DNS и основная проверка такие записи не трогают.
- Старый модуль поиска `RouteDiscovery` удалён.
- 74 юнит-теста проходили успешно на момент выпуска.

### Что означает «алгоритм проверки узлов остался прежним»

- Основные проверки по-прежнему отправляются напрямую на адрес найденного узла
  с `TTL = 64` и размером пакета из текущего шага.
- Размеры пакетов и число попыток по-прежнему задаются пользователем.
- Статистика `Sent`/`Received` обновляется только основными попытками.
- Контрольные проверки потерь по-прежнему выполняются на отдельной копии узла
  через `VerificationHop.Create` и не попадают в счётчики таблицы.
- При `100%` потерях узел получает статус `не отвечает`; после `10` последовательных
  неудач проверка прекращается и узел пропускается на следующих размерах пакета.
- Для проверки остались прежние параметры: `DontFragment = false` и таймаут `3000` мс.
  Новые параметры поиска (`DontFragment = true`, таймаут `5000` мс) используются только
  на этапе discovery.

Изменены только сигнатуры: в `IIcmpProbeClient.SendAsync` добавлен необязательный
параметр `dontFragment`, а `DiagnosticBatch.ProbeAllAsync` получил набор пропускаемых
TTL. Поведение проверки от этого не изменилось.

## 1.1.0

- Лимит трассировки увеличен до `255` хопов.
- Исправлено завышение счётчиков в таблице: контрольные проверки потерь больше не
  добавляются к отправленным и полученным пакетам.
- Добавлен установщик .NET 10 Desktop Runtime и сборка дистрибутива для чистого ПК.
- 70 юнит-тестов проходили успешно на момент выпуска.
